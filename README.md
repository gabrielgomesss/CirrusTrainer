# FlightDeck Academy v7 — pesquisa por página

Inclui 13 documentos, 219 questões e 20 exercícios de ordenação herdados da v6, além de um índice de texto por página dos PDFs.

## Atenção à cobertura
- A indexação percorre todas as páginas dos 13 PDFs, mas apenas páginas com texto extraível entram na busca. Páginas escaneadas/imagens, tabelas e diagramas precisam ser consultados no PDF original.
- A pesquisa de Emergências, Normais, Sistemas e Performance é por palavras-chave: NÃO é um inventário certificado ou completo de checklists.
- Os 20 exercícios de ordenação NÃO abrangem todos os checklists. A transcrição e validação integral dos procedimentos por revisão e matrícula ainda estão pendentes.
- Os materiais podem conter revisões e equipamentos diferentes. Somente estudo em solo; não usar como checklist de voo.
- PDFs publicados no Render Static Site ficam acessíveis publicamente; verifique direitos de distribuição.

Deploy: substitua o conteúdo do repositório, git add ., git commit, git pull --rebase, git push origin main.
